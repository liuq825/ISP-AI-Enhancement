# 许可与供应链检查

## 代码

本仓库使用 MIT License。NAFNet 架构参考的上游实现也是 MIT；归属信息保存在
`NOTICE`。若引入 BasicSR、预训练权重或第三方转换工具，必须另外保存其完整许可，
不能只沿用本仓库许可证。

## 数据和权重

每个训练 run 必须保存：

- 数据集 ID、版本、文件清单 SHA256 和许可快照 SHA256；
- 审批人、审批日期、允许用途和地域/期限限制；
- 初始化权重来源、许可和 SHA256；
- 被排除的数据及原因。

不明确、仅研究、非商业、禁止衍生或禁止再分发的数据默认不能进入生产权重。研究
checkpoint 与生产 checkpoint 必须使用不同的 registry 和访问控制。

## 发布前 SBOM

发布包至少列出 Python/C++ 依赖、模型来源、转换器、DDK、运行时库、许可证、
版本与哈希。法务审批不是可选的模型指标。
