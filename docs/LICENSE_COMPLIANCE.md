## 数据和权重

每个训练 run 必须保存：

- 数据集 ID、版本、文件清单 SHA256 和许可快照 SHA256；
- 审批人、审批日期、允许用途和地域/期限限制；
- 初始化权重来源、许可和 SHA256；
- 被排除的数据及原因。

当前交付是非商业研发模型，因此“仅研究/非商业”数据可以在许可范围内用于技术验证，
但仍不得违反禁止再分发等条款。这里保留严格的 `production` 门禁仅供未来直接商业
发布使用，不是当前 `commercial_grade` 研发训练的阻塞项。

## 发布前 SBOM

发布包至少列出 Python/C++ 依赖、模型来源、转换器、DDK、运行时库、许可证、
